# Security policy

## Supported version

Only the current `main` branch is supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when
available. Do not include real procurement, identity, financial, employee, or
other sensitive documents in a public issue.

This prototype parses selected files in the browser. Treat every audit result
as decision support: a qualified person must verify the source documents and
the applicable rules before taking action.
