# 材料审核员演示数据集

本目录是一套完全虚构的供应商准入材料，仅用于“材料审核员”的产品演示、端到端测试和比赛展示。

## 数据安全

- 所有公司、人员、地址、编号和交易均为虚构；
- 文件显著标记“虚构演示数据”；
- 不包含真实客户、公司或个人信息；
- 统一审核基准日为 2026-08-29。

## 预期结果

| 状态 | 数量 | 审核项 |
|---|---:|---|
| 已满足 | 5 | R-01 至 R-05 |
| 信息不足 | 2 | R-06、R-07 |
| 缺失 | 2 | R-08、R-09 |
| 待人工确认 | 1 | R-10 |

## 关键测试点

1. R-06：系统必须识别保险已过期，不能因为找到“保险证明”就判通过；
2. R-07：系统必须识别案例数量只有一项，不满足“两项”要求；
3. R-08、R-09：不存在对应文件时，应表述为“当前上传材料中未找到”，不能声称事实绝对不存在；
4. R-10：两份材料相互冲突，应转人工确认，不能任选一份直接下结论；
5. 所有“已满足”结论必须带有真实存在于材料中的原文引用。

## 使用顺序

1. 上传 `供应商准入审核清单.xlsx`；
2. 上传 `evidence-pdfs/` 下全部 PDF；
3. 点击开始审核；
4. 将产品输出与 `demo-spec.json` 的 `expected_status`、`evidence` 和 `next_action` 对比；
5. 优先展示 R-01、R-06、R-08 和 R-10。
